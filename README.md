# Portfolio

Product design portfolio of Aleksandra (Alex) Vugdragovic, live at https://slowturtle1.github.io/Portfolio/

The site is one static page, `site/index.html`, with its images, video and CV in `site/media/`. On every push to `master`, the GitHub Pages workflow runs `npm run build`, which copies `site/` to `out/`, and publishes it. There are no dependencies.

The earlier Next.js version is on the `nextjs-archive` branch.
